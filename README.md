# LibreMoodboards

This app was made with the help of AI. LibreMoodboards is a free, open-source moodboard app for Windows, built with Electron. Drop in images, GIFs, videos, audio, text notes, and bookmarks. Organize your files however you want. Released under GPLv3 to keep it free for everyone, forever.

![Screenshot](screenshot.png)

## Features

- 🖼️ Images (including GIFs)
- 🎬 Videos
- 🎵 Audio (SFX, music, etc.)
- 📝 Text notes
- 🔖 Bookmarks
- 🗂️ Free-form organization — arrange things however you want
- 🔒 No accounts, no cloud, no subscriptions — everything stays local
- 🌱 Completely free — no microtransactions, no paywalls.

## Download

Grab the latest portable build from the [Releases page](../../releases). No installer needed — just download, unzip, and run.

## Building from source

```bash
git clone https://github.com/HagHagson/libremoodboards.git
cd libremoodboards
npm install
npm run build
```
